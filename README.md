# Demo Restaurant Website
A demo resturaunt page I made using Webpack module bundler. It allows the user to switch tabs using the navigation buttons. Users can read the menu from the resturaunt as well as contact but it's not fully functional, just a demo.

## Live Demo:
https://bizzyizzymax-bot.github.io/Restaurant-Page/

## Features:
- Switch tabs while staying on the same page using the navigation buttons.

## Tech Stack
Frontend: Css, Html, Javascript, Webpack

## Installation: 
1. Clone the repo.
   git clone
2. Install dependencies
   npm install
3. Start the server
   npm run dev

## What I learned
- How to use the Webpack module bundler
- How to import and export from javascript files
